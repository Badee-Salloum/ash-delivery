## Operational follow-up

Install the signed APK on driver phones outside active shifts. Confirm that Android location and background permission, notifications, battery optimization exemption, SQLite queue, foreground service, and the OEM autostart acknowledgement pass on each device. Monitor the new GPS health diagnostics and coverage in live shifts. An OEM autostart state is a driver acknowledgement because Android does not expose a reliable cross-device read API. The start gate uses app-reported readiness; it is not device attestation. A force-stopped app or a phone that is powered off cannot send a local silence alert; administration will see unknown cause when the phone sends no diagnostics.
